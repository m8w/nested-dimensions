Variables and functions
time, frame, dt
seconds since start (scaled by speed), frame count, seconds per frame
bass, mid, treb
audio bands: about 1 at a steady level, up to 4 on hits, 0 with no audio
bass_att, mid_att, treb_att, vol
smoothed bands, and the average of the three
note, vel, onset, held
last MIDI note and velocity (0–1); onset jumps to 1 on each note and fades; notes held
cc1 – cc16
MIDI controller values (0–1)
track, trackpos, newtrack, lanes
seconds into the newest track, how far through it (0–1), a pulse that jumps to 1 when any track starts and fades, lanes playing
i, n, aspect
plane number (0 MilkDrop A, 1 Stream, 2 MilkDrop B, 3 Nested), plane count, screen width ÷ height
q1 – q8
set in the Camera block, readable in every plane
plane outputs
x y z position · rx ry rz rotation in radians · sx sy scale · a opacity · add 1 for additive glow · bright gain
camera outputs
cx cy cz position · tx ty tz target · fov in degrees · roll · fit distance multiplier · zoom, rot, decay for trails (decay 0 turns them off)

Archive radio, live audio (BlackHole or a mic), camera (OBS Virtual Camera) and MIDI run in the GitHub Pages version of this page. Here, open Sources to play your own audio files nonstop, or load a video file.

Audio

Plays William Victor Newbold’s uploads on archive.org at random, nonstop, favouring tracks this device hasn’t played yet. Recordings over 20 minutes play an 8–14 minute stretch from a random point. To play someone else’s uploads, type a creator name or an archive.org search.

Choose BlackHole to follow the broadcast mix. If the input drops, the page reconnects by itself, and once the browser has allowed the input it starts again on reload. The input never goes to the speakers.

Video

Pick OBS Virtual Camera to put the fractal stream on the Stream plane. It reconnects by itself if OBS restarts the camera.
